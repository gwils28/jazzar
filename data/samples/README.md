# Corpus d'exemple Jazzar

Documents **illustratifs** écrits pour démarrer et tester le système sans archives réelles.
Les faits discographiques (musiciens, dates, labels) sont exacts à notre connaissance ;
les notes étoilées et les formulations critiques sont fictives et marquées `source: sample`.
Ils sont remplacés par les vraies archives dès qu'un PDF est déposé dans `data/raw/`.

Format : Markdown avec un en-tête YAML (`title`, `author`, `doc_type`, `published_on`, `issue`, `review`).
